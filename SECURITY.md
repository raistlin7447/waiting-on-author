# Security

Please report security problems privately through [private vulnerability reporting](https://github.com/raistlin7447/waiting-on-author/security/advisories/new), not in a public issue.

Fixes go into a new release, and the `v1` tag moves to it. Older releases don't get fixes, so pin a newer one if you pinned a SHA.

Examples of what to report: a PR's text or a model's answer that gets the Action to run commands, read its tokens, or change anything other than the label on the repository it's set up for.
